# Blockwright

A free, adaptive WordPress block theme for full-site editing. Light and dark follow each
visitor's own system setting automatically, with no toggle and no second stylesheet, driven
entirely by theme.json design tokens and CSS `light-dark()`. Ships curated color and
typography style variations and a library of block patterns.

**Install from WordPress.org:** https://wordpress.org/themes/blockwright/

Companion plugin (Icon Box, Icon List, Stat Counter, Timeline, a Light/Dark Toggle, dynamic
content, and a curated icon collection): https://wordpress.org/plugins/blockwright-blocks/
